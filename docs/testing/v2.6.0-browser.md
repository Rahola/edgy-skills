# Reproducing the v2.6.0 composition browser checks

Production skills remain Python-standard-library-only and offline. The optional
repository test runner uses Node, Playwright and axe-core for verification.
Install test dependencies outside the checkout if desired:

```bash
npm install --prefix /tmp/edgy-browser playwright@1.62.1 @axe-core/playwright@4.14.0
export NODE_PATH=/tmp/edgy-browser/node_modules
export EDGY_CHROMIUM=/usr/bin/google-chrome
python3 tools/check-walkthrough.py
node tools/test-walkthrough.cjs
bash tools/check.sh
```

A regular Chromium/Chrome binary or a Playwright-installed Chromium is required;
omit EDGY_CHROMIUM to try standard Linux locations or Playwright's default.
Set `EDGY_TEST_OUT` to an output directory for JSON reports, screenshots and PDF.
The runner prints its evidence location and records actual browser/Node versions.
`EDGY_SINGLE_PROCESS=1` is available for constrained headless environments; it
changes launch flags, not assertions. Do not pass a Chrome-CLI adapter here.
No private scratch adapter is required. CI installs test dependencies separately
and runs both the repository gate and this runner. Dependency downloads are test
setup, never a generated presentation's network dependency.

The runner covers file:// and local HTTP, same-origin srcdoc, targeting and
history, hostile data, all-section return, local notes/export, viewports, print
and automated accessibility scans. It does not certify WCAG conformance or
substitute for human facilitation and screen-reader tasks in the test plan.
